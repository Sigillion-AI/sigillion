# Contributing

Sigillion's code is not in this repository and is not open source (see LICENSE); the packages are on PyPI. What this
repository takes:

- **Bug reports**, as issues: what you did, what happened, what you expected, the version (`pipx list`), the operating
  system and the lines `sigillion status` prints. Never the text of your sessions, an e-mail address or anything
  private: issues are public. If Sigillion stopped or refused something, its log is in `~/.sigillion/claude-code/logs/`;
  quote the line, not the file.
- **Questions and ideas**, in Discussions.
- **Your numbers**: the four lines `sigillion status --actions` prints, pasted as they are, in Discussions or by e-mail
  to info@sigillion.com. They decide what is built next.
- **Corrections** to this repository's texts (the README, the privacy note, the website): an issue, or a pull request
  against the file.
- **Security**: never in an issue. See SECURITY.md.

We answer every issue. What is built next follows the first users' numbers, in the plan's order: Claude Code solid
first, then every other agent, then legal and finance.
