Sigillion

Remember everything. Read almost nothing. Prove all of it.

Sigillion is memory for AI agents, made by Steddy Nova SRL. It keeps the whole record of what an agent and a person did, word for word, on your own computer; compressed, so that a model can skim weeks of work in a few hundred tokens and open the full text only where it needs it; sealed, so that every record can be checked to show it was not altered. No telemetry: Sigillion itself sends nothing anywhere. What it hands the agent becomes part of your session, which Claude Code sends to Anthropic and Cursor to the models it uses, as each does with the rest.

One engine, in order

  1. Claude Code and Cursor first. Today Sigillion works in Claude Code and in Cursor: every session is kept after compaction and after Claude Code deletes its transcripts. Claude searches and reopens its own history while it works. Both agents keep their sessions in one store on your computer: in the same project, Cursor's agent can recall what Claude Code did. Claude can recall what you did in Cursor. Claude Code is where every feature is built, measured and proved on real work. It is the first step, not the whole idea.
  2. Every AI model and agent tool next. The engine does not depend on one model. The same sealed memory will sit under other models and the tools people already use (coding agents, agent frameworks, assistants), with an SDK for anyone who builds agents.
  3. Then the fields where the record must stand: legal and finance. The same store, with a pack for each field: its citations and terms, its redaction rules and receipts that show what the model did and when, for work a client, a regulator or a court may ask about.

Each step comes after the one before has proved itself with other people's numbers, not before.

Install

Windows or Linux on a 64-bit Intel or AMD processor (x86_64); or a Mac with Apple silicon (M1 or later) and macOS 11 or later. Python 3.10 to 3.14. Claude Code 2.1.287 or later or Cursor. pipx. Not yet: a Mac with an Intel processor, ARM processors, Alpine Linux. The details, Python 3.15 and the upgrade from an earlier version are in the README.

pipx install --include-deps sigillion
sigillion install
sigillion install cursor

sigillion install is for Claude Code and sigillion install cursor for Cursor: use one of them or both. After sigillion install cursor, restart Cursor once.

sigillion status shows what is kept; sigillion status --actions shows what Sigillion did for you, in four lines of counts you can share as they are; sigillion --help lists every command. To take it out: sigillion uninstall (in Cursor: sigillion uninstall cursor), then pipx uninstall sigillion; what was kept stays in ~/.sigillion until you delete it.

Free for users, not for companies

Sigillion is free for personal, non-commercial use. Recording, the brief at a session's start, search and recall, receipts and export: all of it, with no trial and no licence key to ask for. Use for or within a company or another organisation needs our written permission first. So does use for work you are paid for. Write to info@sigillion.com.

What will be paid, from a later version. Encryption of what Sigillion keeps; tamper-proofing: each record signed on your computer and anchored so that it can be proved outside your computer, with sigillion prove to make the proof of one turn for you to hand to someone; and a third agent tool or more on the same memory. Everything you use today stays free for personal use: any two agent tools on one memory (today Claude Code and Cursor), recording, the brief, search and recall, receipts and export. Checking stays free in every version: sigillion verify and sigillion-reader check hashes, signatures, anchors and receipts, so anyone you give a proof to can check it with no licence. sigillion-reader also lists and extracts everything kept, with or without a licence. A version you already installed keeps the terms it came with. Founder licence holders get the paid features free.

Not open source and not open core: there is one Sigillion, closed and free for personal use. Already have a founder licence? You will hear from us by e-mail as the project moves forward.
