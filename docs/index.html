Sigillion

Remember everything. Read almost nothing. Prove all of it.

Sigillion is memory for AI agents, made by Steddy Nova SRL. It keeps the whole record of what an agent and a person did, word for word, on your own computer; compressed, so that a model can skim weeks of work in a few hundred tokens and open the full text only where it needs it; sealed, so that every record can be checked to show it was not altered. No telemetry: Sigillion itself sends nothing anywhere. What it hands Claude becomes part of your Claude Code session, which Claude Code sends to Anthropic as it does the rest.

One engine, in order

  1. Claude Code first. Today Sigillion ships as a Claude Code plugin: every session is kept after compaction and after Claude Code deletes its transcripts, and Claude searches and reopens its own history while it works. Claude Code is where every feature is built, measured and proved on real work. It is the first step, not the whole idea.
  2. Every AI model and agent tool next. The engine does not depend on one model. The same sealed memory will sit under other models and the tools people already use (coding agents, agent frameworks, assistants), with an SDK for anyone who builds agents.
  3. Then the fields where the record must stand: legal and finance. The same store, with a pack for each field: its citations and terms, its redaction rules, and receipts that show what the model did and when, for work a client, a regulator or a court may ask about.

Each step comes after the one before has proved itself with other people's numbers, not before.

Install

Windows or Linux on a 64-bit Intel or AMD processor (x86_64); Python 3.10 to 3.14; Claude Code 2.1.287 or later; pipx. Not yet: macOS, ARM processors, Alpine Linux. The details, Python 3.15 included, are in the README.

pipx install --include-deps sigillion
sigillion install

sigillion status shows what is kept; sigillion status --actions shows what Sigillion did for you, in four lines of counts you can share as they are; sigillion --help lists every command. To take it out: sigillion uninstall, then pipx uninstall sigillion; what was kept stays in ~/.sigillion until you delete it.

  • Recording is free for good; reading sessions back needs a licence after a 30-day trial; exporting everything kept always works, with or without one.
  • How it ships: the engine compiled; the storage format and the capture (what touches your transcripts) as readable source. Sigillion is not open source: all rights are reserved by Steddy Nova SRL. The terms.
  • Search by meaning is being worked on: today recall finds words, a prefix or a handle.

Privacy

Sigillion runs on your computer and sends nothing to us or to anyone: no account, no telemetry, no update check, and its licence is checked offline.
